# iPhone Mirroring benchmark — 2026-09-04

## Environment

- macOS 27.0 on arm64
- iPhone Mirroring bundle `com.apple.ScreenContinuity`
- `yutori-mcp` 0.5.11 workspace at commit `cf6e91c`
- Yutori SDK 0.9.13
- CUA Driver 0.23.2
- Mirroring window: approximately 477x1049 points
- Exact-window capture: approximately 713x1568 pixels, valid frame

`computer-use doctor` passed every blocking and optional check before the run.
The mirrored iPhone content was available as a screenshot but not as semantic
macOS accessibility elements, so the model used vision and pixel actions.

## Findings

1. **The core route is viable.** Exact-window capture is fast (about 0.4 s per
   screenshot in the successful runs), pixel taps work without focus theft,
   and a complete Calculator task finishes in roughly 30–35 seconds.
2. **Strict background mode works for touch-first tasks.** The confirmation run
   completed with no foreground fallback and no refusal.
3. **Background typing is the weak link.** Spotlight text did not land until a
   single foreground retry. Strict-background operation therefore accepts that
   keyboard-heavy tasks may stop with a reported delivery blocker.
4. **Broad navigation prompts are inefficient.** The first run eventually
   reached Calculator but wandered away and exhausted its four-minute deadline.
   The skill should use `Command-3`, exact app name, and Return instead of
   scanning Home screens.
5. **Window scoping is important for privacy.** Foreground mode can observe the
   whole Mac desktop. Home, Spotlight, App Switcher, widgets, badges, and search
   results can expose unrelated personal data even when the requested task is
   harmless.
6. **The iPhone UI is pixel-only from macOS's perspective.** The Mac AX tree
   contains iPhone Mirroring's chrome, not the controls inside the phone frame.
   A native Android/iOS driver could add semantic targeting later.

## Decision

**Decision: keep purely experimental and limited to bounded, low-risk evaluations.**

Use strict background window scope, never escalate to foreground from the
iPhone-specific workflow, launch apps through iPhone Spotlight when background
typing works, and require explicit warnings about mirrored personal content. This benchmark is not yet broad
enough for a general reliability claim; expand next with a privacy-safe fixture
app covering long-press, vertical/horizontal swipe, text input, scrolling,
Home/App Switcher, rotation, Resume, and Stop.
